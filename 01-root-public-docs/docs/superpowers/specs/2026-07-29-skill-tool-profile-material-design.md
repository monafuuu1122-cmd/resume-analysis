# “技能和工具”补充资料设计

## 目标

在经历档案的“个人补充资料”中增加独立的“技能和工具”类型，用于记录无法自然绑定到某段实习经历的技能、软件和工作工具。

## 数据与交互

- `ProfileMaterial.type` 增加 `skill_tool`，旧数据保持兼容。
- 资料类型下拉框增加“技能和工具”。
- 该类型填写名称、具体说明，并允许填写可选的熟练度。
- 保存、展示、单条删除、备份、迁移和导入沿用现有资料流程。

## 下游使用

- 能力星图将 `skill_tool` 映射为 `tool`，不再错误归入证书。
- 岗位方向、JD 分析、企业研究和面试上下文继续读取完整 `profileMaterials`，因此新资料会自动进入现有 AI 上下文。
- 千问只能使用用户填写的名称、说明和熟练度，不得推断未提供的使用经验。

## 验证

- Schema 接受 `skill_tool` 并继续接受三种旧类型。
- 经历档案可新增和删除“技能和工具”资料。
- 能力星图显示该资料为工具。
- 现有测试、类型检查和构建保持通过。
