# Offer 探险日

面向 2027 届秋招/校招的本地优先网页看板。它将工作产出保留在经历原文中，再提炼可核验的能力、工具、AI 运用和证书证据，并支持 JD 适配、企业研究、面试重点拆解、双语回答优化与连续模拟面试。

## 启动

需要 Node.js 20+。

```bash
npm install
cp .env.example .env
npm run dev
```

在 Google Chrome 打开 `http://localhost:5173/`。生产构建使用：

```bash
npm run build
npm start
```

## 静态 HTML 导出

如果需要单独拿到网页前端文件，可以运行：

```bash
npm run build:html
```

命令会生成 `html-export/` 静态前端文件夹。部署时需要让它与当前 Worker API 同源提供，才能继续使用 DeepSeek 分析、岗位匹配和面试功能。不要把 DeepSeek API Key 写进 HTML、前端环境变量或静态资源；浏览器不需要直接连接 DeepSeek，也不需要在浏览器配置代理。实际可用性取决于网站域名可访问性和 Worker 到 DeepSeek 的出站网络连通性。

需要在本机直接预览静态 HTML 并保留智能分析时，使用：

```bash
npm run local:html
```

该命令会先生成 `html-export/`，再启动同源本地 API 服务（默认 `http://localhost:4173`）。它会读取项目根目录 `.env`；密钥只进入本地服务进程，不会写入 HTML。请不要双击 `html-export/index.html`，`file://` 页面没有同源 API，无法完成 JD 分析。

## AI 配置

- DeepSeek：默认由部署管理员在生产 Worker 配置 `DEEPSEEK_API_KEY`，也可在“服务设置”为当前浏览器填写个人 Key；个人 Key 只进入本站同源请求，不进入备份或模型提示词。模型默认使用 `deepseek-v4-flash`。
- Base URL 固定为 `https://api.deepseek.com`。JD 分析默认允许 120 秒，单轮追问等短任务使用更短上限；所有任务仍受统一服务端取消和超时保护。
- 企业研究仅使用 DeepSeek 已有知识进行归纳，不进行实时联网搜索，也不展示伪造来源；知识不足时会明确显示“现有知识不足”。
- 生产 Worker 的所有 DeepSeek 请求统一经过服务端网关，并按任务设置 30—120 秒上限。超时会真正取消上游请求并返回 `DEEPSEEK_TIMEOUT`；用户取消返回 `DEEPSEEK_ABORTED`。页面只更新当前任务提示，不清空已经保存的分析、研究、回答或面试轮次。
- 超时可通过 `.env.example` 中的 `DEEPSEEK_TIMEOUT_*_MS` 环境变量覆盖；非法值会回退到安全默认值。模拟面试单轮默认 30 秒，常规生成 45—60 秒，JD 分析与企业研究默认 120 秒，完整复盘 90 秒。
- 当前生产 Worker 使用非流式 JSON 响应；不存在后台继续完成用户正在等待的DeepSeek任务，也不使用无限自动重试。
- 部署时需启用 `enable_request_signal` 兼容标志，使浏览器关闭或主动取消能通过 `Request.signal` 立即传入统一网关。

## 面试流程

JD 实验室先在独立的“企业目标”卡片中添加企业名称，可选填官网与行业；企业可逐条选择或删除。所选企业会作为结构化身份贯穿 JD 分析、企业研究、回答优化和模拟面试，不再依赖模型从长 JD 中猜名称。旧 JD 可直接绑定新企业，无需重新上传；绑定发生变化时，旧企业的研究和面试缓存会自动失效。

完成 JD 分析后，可在结果页生成“面试重点拆解”，查看企业与人才画像、岗位能力矩阵、重点准备和高概率问题。企业画像来自 DeepSeek 已有知识，统一标记为模型推断；知识不足时不会补造。每道高概率问题都可单独“练习这道题”，使用文字或浏览器语音转写回答后获得一次点评和改进建议。点击“开始模拟面试”后，可独立进入：

- 回答优化：结合当前 JD、简历证据和企业研究生成可口述的中英双语回答；缺失事实使用占位符。
- HR 面：练习自我介绍、求职动机、企业/岗位选择与经历核实。
- 业务面：围绕业务理解、JD 核心能力和场景/行为题逐步追问。
- 两种面试都支持文字/语音转写、暂停、继续、结束复盘和报告导出；AI 内容仅用于练习，不代表真实录用判断。

旧 JD 记录没有面试研究时仍可打开，按页面提示补充生成即可。模型研究失败不会覆盖已有 JD 分析。

## 岗位方向

岗位方向不再限制为四项。历史四个方向首次打开时会作为可删除的初始项迁移；你可以新增、删除并标记主方向、备选方向或感兴趣状态。每个方向会重新读取经历原文、确认证据、证书、语言与 AI 应用资料，区分直接证据和可迁移能力。

“获取岗位灵感”会先检查服务端DeepSeek鉴权与模型状态，再根据完整经历证据生成非固定方向。推荐项可加入方向、排除或再次生成；被排除的反馈会用于后续去重。刷新失败时保留上一次成功结果，岗位方向与反馈也会进入本地备份。

展开某个方向后可生成“市场岗位画像”。系统根据 DeepSeek 已有岗位知识归纳主流要求，并逐条展示 3—4 条档案短证据、匹配原因、准备建议、需补充能力和岗位思维；不进行联网搜索。模型内部使用的证据编号不会显示在页面结果中。

## 本地数据与旧网址迁移

- 首页按资料、岗位、JD 和面试模块分别读取数据；单个模块失败时会保留其他可用进度，并区分空数据、部分失败和读取失败。
- 同一网址中的旧版记录会在首次读取时自动迁移，迁移前保留快照；重复经历通过组织、角色、项目、日期和原始内容指纹去重，损坏记录进入恢复区而不会覆盖现有数据。
- 浏览器会按网址隔离 IndexedDB。若数据来自旧域名、`localhost` 或 `127.0.0.1`，请在旧网址“经历档案—旧版数据与迁移”中导出 JSON，再到新网址导入。数据包不包含DeepSeek API Key。
- 如果浏览器拒绝文件选择，也可以在“旧版数据与迁移”展开“粘贴数据包内容”，将 JSON 粘贴后导入；仍使用同一套校验、去重和快照逻辑。
- 岗位灵感请求支持取消、60 秒超时、重试和纯错误降级；任何完成路径都会解除加载状态。

## 语音与隐私

- 语音使用 Chrome Web Speech API；麦克风拒绝或识别失败时自动保留文字入口。
- 转写文字可编辑后再提交。应用不创建、不上传、不长期保存原始录音。
- 经历、JD、分析和面试记录默认保存在当前浏览器 IndexedDB。
- 日志不得记录完整简历、原始录音或任何 API Key。
